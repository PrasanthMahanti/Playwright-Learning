# Day 2: Terminal Basics

Learned:
- A terminal is a text window where I give my computer written instructions.
- pwd shows where I am. ls lists files and folders. cd enters a folder. cd .. goes up one level.
- mkdir creates a folder. New-Item creates a file. cat shows what is inside a file.
